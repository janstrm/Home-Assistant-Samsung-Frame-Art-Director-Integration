# Security policy

## Supported versions

Security fixes are applied to the latest released version of Samsung Frame Art
Director. Please update before reporting a problem that may already be fixed.

## Reporting a vulnerability

Please report vulnerabilities privately through
[GitHub Security Advisories](https://github.com/janstrm/Home-Assistant-Samsung-Frame-Art-Director-Integration/security/advisories/new).
Include the affected integration and Home Assistant versions, reproduction
steps, and the expected impact. Do not include TV tokens, API keys, private URLs,
or other secrets in logs or screenshots.

If private reporting is unavailable, open a public issue containing no sensitive
details and ask the maintainer for a private contact channel.
